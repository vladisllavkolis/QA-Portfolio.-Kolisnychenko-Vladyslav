Task 1. Database Creation and Data Population
Create the Universities, Faculties, Groups, and Students tables in a database. Establish relationships between the tables using primary keys and foreign keys. Populate the tables with test data according to the specified requirements, including universities whose names contain the letter “У”, groups for courses 1–5, and a student named Ivan.
2. SQL SELECT Queries
Write SQL queries to retrieve data from the database tables. Implement queries to select all university fields, students’ first and last names, students named Ivan, groups with numbers greater than 300, and universities whose names contain the letter “У”.
Task 3. Data Sorting (SQL ORDER BY)
Sort the records in the Students table in alphabetical order and reverse alphabetical order using the SQL ORDER BY statement.
Task 4. Joining Tables Using JOIN (SQL JOIN)
Create an SQL query to join the Students and Groups tables using the JOIN statement and the relationship between students and their study groups through the GroupId foreign key.
